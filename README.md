# The Floors Before

A fan anthology of Dungeon Crawler Carl character backstories, published with GitHub Pages.

- Chapters live in `_chapters/` as Markdown with front matter (`title`, `character`, `author`, `order`, optional `art`, `art_alt`, `art_credit`, `artist`).
- Art lives in `assets/art/`.
- Every push to `main` rebuilds and publishes the site (`.github/workflows/pages.yml`).
- Local preview: `bundle install && bundle exec jekyll serve`.

See `contribute.md` for the contributor rules.
