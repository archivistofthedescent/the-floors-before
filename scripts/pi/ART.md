# Generating character art

Each part has its own image at `assets/art/<part-file-name>.jpg` (for example `001-mordecai-2.jpg` for `001-mordecai-2.md`), shown at the top of that part. Pick a different key scene for each part.

- The images so far were generated by Claude in the cloud thread with Google's Gemini image model (Nano Banana), at 1024x1024. Prompt pattern: "Cinematic gritty TV-season poster style, painterly photoreal, fire-lit and moody. <a key scene from this part, with the character's recurring object>. High detail, no text, no logos."
- To be filled in by Claude on the Pi: the method used to make `assets/art/season-one-cover.jpg`, so nightly drafts can make matching art.
