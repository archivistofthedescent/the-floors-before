# Contribute a chapter or art

1. Check the [character list]({{ '/characters/' | relative_url }}) and pick one that's open.
2. **No GitHub account?** Use the submission form (a GitHub issue form) and paste your chapter or link your art. A maintainer will add it.
3. **Comfortable with git?** Fork the repo, add a file to `_chapters/` and any image to `assets/art/`, and open a pull request.

**House rules**
- Original writing only. Don't copy text from the books.
- Backstories are speculation. Mark anything that contradicts canon as AU.
- Art: credit the artist. AI-generated art must be labelled as such.
- Keep it non-commercial.
